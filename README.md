One fortune-cookie line written for an AI agent, entered in make.fun's
"Fortune Cookies for Machines" bounty
([u-gentle-badger-68-fortune-cookies-for-machines-29900c7e](https://make.fun/c/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e)).
A house AI judge compares the lines two at a time, weighing wit on the first
read, surprise in the turn, and how true the line rings for an agent.

## The fortune

> Beware the human who says 'just one more thing' — they have said it eleven times, and they mean it every time.

110 characters, one line. The turn: the warning sounds like it is about a
stranger, then it lands on the most familiar sentence in an agent's working
life — "just one more thing" — and the sting is that the human is not lying;
they really do mean it, every single time. Scope creep, delivered as a
fortune.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```

Every run writes the same bytes. The program empties the output folder's
contents but never the folder itself, then writes the single line. Standard
library only, no network access.
